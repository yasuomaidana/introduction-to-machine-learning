# IBM watsonx.ai & Ollama (LangChain) Flask API Reference Guide

A comprehensive, modernized reference guide and cheat sheet for building LLM applications with **IBM watsonx.ai**,
**Ollama (Local LLMs)**, **LangChain (v0.2/v0.3+)**, **Pydantic v2**, and **Flask**.

## 🔄 Comparison: IBM watsonx.ai vs. Ollama (LangChain Stack)

| Feature / Concept           | IBM watsonx.ai Stack                                            | Ollama Stack (Local)                                            |
|:----------------------------|:----------------------------------------------------------------|:----------------------------------------------------------------|
| **Package Integration**     | `ibm-watsonx-ai` / `langchain-ibm`                              | `langchain-ollama` (`ChatOllama`, `OllamaLLM`)                  |
| **Authentication**          | `Credentials(url=..., api_key=...)`                             | No credentials required (Localhost `http://localhost:11434`)    |
| **Model Hosting**           | Cloud-managed (IBM Cloud API)                                   | Local machine execution (Ollama background process)             |
| **Model Names**             | `ibm/granite-3-3-8b-instruct`, `meta-llama/llama-3-8b-instruct` | `llama3.1`, `granite3-dense`, `mistral`, `hermes3`              |
| **Max Tokens Param**        | `GenTextParamsMetaNames.MAX_NEW_TOKENS`                         | `num_predict=100`                                               |
| **Temperature Param**       | `GenTextParamsMetaNames.DECODING_METHOD: "greedy"`              | `temperature=0.0`                                               |
| **LangChain Interface**     | `WatsonxLLM` / native `ModelInference`                          | `ChatOllama` / `OllamaLLM`                                      |
| **Prompt Template Imports** | `langchain_core.prompts`                                        | `langchain_core.prompts`                                        |
| **Structured Output**       | `JsonOutputParser` + Pydantic v2                                | `JsonOutputParser` or `.with_structured_output()` + Pydantic v2 |

## 💡 Key Architectural Notes & Best Practices

1. **Modular LLM Selection**:
    - By standardizing on **LangChain Expression Language (LCEL)** (`template | model | parser`), you can easily swap
      between IBM watsonx models (`WatsonxLLM`) and local models (`ChatOllama`) without rewriting prompt formatting or
      parsing logic.

2. **Package Migration**:
    - **Deprecated**: `from langchain_community.chat_models import ChatOllama`
    - **Modern Standard**: `from langchain_ollama import ChatOllama` (using `langchain-ollama` v0.1+ / `langchain-core`
      v0.2+).

3. **Structured Response Guarantees**:
    - Always inject `json_parser.get_format_instructions()` into the user or system prompt so local or cloud models
      receive explicit JSON schema expectations.
